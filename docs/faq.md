# GXU 研课表 · 常见问题

面向广西大学研究生的非官方开源校园信息查询应用。本文档只描述**本仓库 GXU 维护线**的行为；上游 Traintime PDA / XDYou 的行为不在本文范围内。

> [!IMPORTANT]
> 非官方应用，不代表广西大学官方立场。数据来自学校各信息系统的公开接口，应用只做本地展示与整理。**教务口径一律以学校官方系统为准。**

## 如何获取与安装

推荐从[官网 gxu.app](https://gxu.app/downloads/)下载，会自动匹配架构；备用渠道是 [GitHub Releases](https://github.com/GaleBird/traintime-pda-gxu/releases)。

预编译包目前**只有 Android**，分 `arm64-v8a` / `armeabi-v7a` / `x86_64` 三种 ABI。绝大多数近几年的手机选 `arm64-v8a`。不确定就先装 `arm64-v8a`，装的进去说明对了。

iOS、Linux、Windows 没有发布预编译包，需要自行从源码构建，见仓库根目录 [`README.md`](../README.md#构建)。

**安装提示"未知来源"或"已阻止安装"**：这是 Android 对非应用商店包的常规拦截，需在系统设置里为该来源（文件管理器 / 浏览器）授权后再装。

**装不上、提示签名冲突**：如果之前装过上游 XDYou 或其它渠道的包，签名不同无法覆盖安装，请先卸载旧版再装。

## 登录相关

本应用使用广西大学统一认证登录，支持两种方式：

- **账号登录** —— 学号 + 一站式登录密码
- **短信登录** —— 手机号 + 短信验证码

登录成功后登录态会**加密保存在本地**，之后打开应用无需重复登录。

### 登录失败怎么办

按下面顺序排查：

1. **先确认账号密码本身可用**：在电脑或手机浏览器里打开学校一站式，用同样的账号密码试着登录一次。浏览器都登不上，说明问题在账号侧，请走学校官方渠道（如一站式或信息化部门的找回密码入口）处理，应用侧无法代为解决。
2. **点"清除登录缓存"再重试**：应用里可能残留了上一次的失效会话。清除后重新登录。
3. **看错误提示的具体内容**：应用会把"无法连接到服务器""响应状态码 xxx""服务端返回的 message"分别展示，据此判断是网络问题、认证被拒还是服务端异常。
4. **还不行就抓登录日志**：点击"查看网络交互"，导出登录过程中的请求交互记录，连同上面的错误提示一起反馈（见[遇到错误怎么反馈](#遇到错误怎么反馈)）。

### 提示"登录后处理"很久没反应

登录成功后应用还要继续拉取学期信息与课表数据，这一步本身就比较慢。如果长时间卡住，可以退出应用重新进入；如果反复卡在同一处，请按上面的第 4 步抓日志反馈。

### 忘记密码

应用内的"忘记密码"会打开学校官方找回入口。**注意**：官方找回页面在跳转过程中可能进入非学校域名的登记页面，应用不会自动填入任何凭据。遇到这种情况，建议直接在可信网络环境下用系统浏览器自行打开学校官方入口处理。

### 账号设置里的其它密码

设置 → 账号设置里可以填写**校园网查询密码**等可选凭据，这些只在对应功能里使用。不填不影响登录，只是查不了对应内容。具体见下面各功能小节。

## 更新与版本号

版本号形如 `1.0.7+51`，`+` 前面的 `1.0.7` 是版本名，后面的 `51` 是构建号。**判断新旧看构建号**。

应用内"设置 → 关于 → 检查软件更新"会去读项目自有的远端版本清单，并用 **RSA-SHA256 签名校验**清单内容后再提示更新，防止被中间人替换成伪造的下载地址。清单本身不带安装包，更新时会跳转到对应的下载页。

- 提示"目前您正在运行最新版" —— 已是最新
- 提示"当前仓库还没有发布正式版本" —— 远端清单读取正常，只是没有发布记录
- 提示"获取更新信息失败" —— 网络问题，稍后重试

**不要手动降级安装**，低构建号的包会被更新逻辑判定为"有新版本"而反复提示。

## 课表与日程

课表数据来自 GXU 研究生系统，展示在首页日程表。

### 数据不刷新 / 课表变了但应用没变

课表结果会在本地缓存。在应用右上角的课表菜单里选**"刷新日程表"**，或在设置 → 课表相关设置里点**"强制刷新课表"**。后者会绕过缓存直接回学校后端重新获取，耗时明显更久，属正常现象。

### 想改课程显示

课表菜单里的"添加课程信息"可以手动补充课程；"清除所有用户添加课程"只清除你手动加的，不影响从学校获取的数据。

### 导出日程

课表菜单里：

- **生成日历文件** —— 导出为 iCalendar（`.ics`），可导入任意日历应用
- **输出到系统日历** —— 直接把日程写进系统日历

### 和同学共享课表

课表菜单里"生成共享课表文件"可以导出一份课表文件发给同学，对方用"导入共享课表文件"导入。**共享文件包含你的个人信息，请勿随意公开或转发到公开群**。导入他人文件后想删掉，用"删除共享课表文件"。

### 切换学期

课表菜单或设置里的"修改学期"可以切换要查看的学期。

### 上课提醒收不到

去设置 → 通知设置 → 课前通知设置检查：

1. 应用的通知权限是否授予（页面里会显示"已授予 / 未授予"）
2. 精确时间权限是否授予 —— Android 13+ 如果没有精确闹钟权限，提醒时间只能粗略对齐
3. 通知日程是否已安排（页面会显示已安排的通知条数）
4. 系统是否对应用做了省电限制，国产安卓尤其常见

检查完点"更新通知日程"重新排一次。

## 成绩与选课

**成绩查询**与**选课情况**都来自研究生系统。

- 查询结果会写入**本地加密缓存**，避免频繁请求学校系统；页面上的刷新按钮会绕过缓存强制重新拉取
- 如果拉取远端失败而本地有缓存，应用会**回退显示缓存内容**并标注，不会直接白屏报错
- 缓存文件损坏时会自动丢弃并重新从远端获取，不会卡死页面

### 成绩里的均分/绩点计算

成绩页的计算器可以自选科目计算。默认会忽略部分课程类型。计算口径是应用侧的近似，**学分绩点以学校官方认定为准**。

### 选课数据看起来是旧的

选课结果缓存有效期为 24 小时。切换学期或手动刷新可以获取最新数据。

### 物理实验 / 体育系统 / XDU Planet 在哪

这些是上游 XDYou 面向西电的功能，**本 GXU 版本未接入**，应用内不提供入口。设置里即使出现相关项也与数据源无关，不影响正常使用。

## 校园网用量

校园网查询需要**你的校园网账号密码**（不是统一认证密码）。请在设置 → 账号设置 → 校园网账号密码设置里填写，不填则查不了网费。

查询结果同样本地加密缓存。

学校校园网系统的原始返回数据里，同一台在线设备可能重复出现多条记录，这是上游数据本身的特点，应用未做去重加工。

## 空闲教室

数据来自研究生系统的空闲教室查询，按教学楼栋查看各时段的空闲情况。

## 隐私与数据安全

- **没有遥测与埋点**。应用不向任何第三方统计服务上报你的使用行为。
- **凭据与缓存加密落盘**。登录 Cookie、成绩 / 选课 / 校园网 / 课表缓存都以加密形式保存，不以明文写入磁盘。
- **凭据只用于对应的学校系统**。应用不把账号密码发给学校系统之外的任何服务。
- **更新清单验签**。见[更新与版本号](#更新与版本号)。

如果想彻底清掉本机数据：设置 → 缓存登录设置 → **"退出登录并重启应用"**（清除登录态与相关数据），或 **"清除缓存后重启"**（只清缓存，保留登录）。

## 遇到错误怎么反馈

反馈入口：[GitHub Issues](https://github.com/GaleBird/traintime-pda-gxu/issues)

提 Issue 前先搜一下有没有相同问题。提的时候请附上：

- **应用版本号** —— 设置 → 关于里可见，形如 `1.0.7+51`
- **手机型号与系统版本**
- **你在做什么的时候出的错** —— 这一步最重要，只有错误类型没有操作上下文基本无法定位
- **错误提示的原文或截图**
- **相关日志** —— 设置 → 缓存登录设置 → **"查看网络拦截器和日志"**，重点看是否有 `watermeter` 字样的调用栈信息
- **是否可复现**，能给出复现步骤最好

如果是某个页面**解析失败**（提示数据结构变化、字段找不到之类），请说明是哪个功能、哪个页面。

**安全问题请勿开公开 Issue**，先在 Issue 里说明"需要私密沟通"，维护者会另开渠道对接。

**上游代码本身的缺陷**请提到[上游仓库](https://github.com/BenderBlog/traintime_pda)。

## 与上游项目的关系

本项目基于 [BenderBlog/traintime_pda](https://github.com/BenderBlog/traintime_pda)（Traintime PDA / XDYou）继续维护，但已是一条**独立的维护线**：

- 按"广西大学单校"处理，数据源与登录流全部对接 GXU 系统，不保留 XDU/GXU 双校切换
- 品牌、图标、官网、更新清单与签名密钥均为本项目自有
- 不与上游保持代码同步，也不追加上游的新功能

上游的开发团队与历届贡献者提供了本项目的功能基础与开源代码，一并致谢，名单见 [`contributors.md`](contributors.md)。上游的 App Store / F-Droid 发布与本项目无关。

仓库层面的约定见 [`repository_standalone.md`](repository_standalone.md)。

## 参与开发

代码在 [GaleBird/traintime-pda-gxu](https://github.com/GaleBird/traintime-pda-gxu)，构建方式见仓库根目录 [`README.md`](../README.md#构建)。

本仓库当前不接纳大规模重构类 PR。修复类改动（页面解析失效、崩溃、文案错误）欢迎直接提；提之前请先跑通：

```bash
.flutter/bin/flutter analyze
.flutter/bin/flutter test
.flutter/bin/dart run tool/security_audit.dart
```

涉及缓存写入或 Cookie 存储的改动，必须遵守 [`AGENTS.md`](../AGENTS.md) 里记录的加密存储约定。
